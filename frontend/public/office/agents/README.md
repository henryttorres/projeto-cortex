# Avatares do Escritorio IA

Adicione avatares opcionais com estes nomes:

- `<agent>-idle.webp` para a imagem estavel;
- `<agent>-active.mp4` para a animacao curta da sala ativa ou selecionada.

Agentes reconhecidos: `coordinator`, `security`, `supervisor`, `customer`,
`professor`, `personas` e `bugger`. Sem arquivo de midia, a interface usa um
avatar SVG leve como fallback. Videos nao sao carregados fora da sala ativa ou
selecionada.

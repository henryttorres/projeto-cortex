# Fundos do Escritorio IA

Os fundos opcionais seguem os nomes:

- `ala1-bg.webp` para Recepcao, Seguranca e supervisao, Inteligencia do aluno
  e Sala de aula;
- `ala2-bg.webp` para o Laboratorio de personas e a Oficina Bugger.

Sem esses arquivos, a planta usa fundos CSS leves. A interface verifica a
presenca das imagens sem exigir que elas sejam entregues com o codigo.
